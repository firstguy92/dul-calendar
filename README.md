# 둘의 달력 설치 안내

두 사람의 생리 주기 기록을 암호화해서 자동으로 동기화하는 개인용 웹앱이에요.
기록은 폰에서 암호화된 뒤에 서버로 올라가요. 그래서 서버(Supabase)에는 연결 코드를 가진 두 사람만 열 수 있는 암호문만 남아요.

## 1. Supabase 준비 (약 5분)

1. https://supabase.com 에 가입하고 **New project**를 만들어요. 지역은 Seoul(ap-northeast-2)을 고르면 빨라요.
2. 왼쪽 메뉴의 **SQL Editor**를 열고, `schema.sql` 내용을 통째로 붙여넣은 뒤 **Run**을 눌러요.
3. **Project Settings → API Keys**(또는 API)에서 두 가지를 복사해요.
   - Project URL (예: `https://abcd1234.supabase.co`)
   - Publishable key(`sb_publishable_...`) 또는 예전 방식의 anon key(`eyJ...`)
4. `config.js`를 열어 두 값을 넣어요. **secret key나 service_role key는 절대 넣지 마세요.**

## 2. 웹에 올리기 (무료)

암호화 기능과 홈 화면 앱 기능은 https 주소에서만 동작해요. 둘 중 편한 방법을 쓰세요.

**Netlify Drop (가장 쉬움)**
1. https://app.netlify.com/drop 에 접속해요.
2. 이 폴더를 통째로 끌어다 놓으면 주소가 바로 생겨요. 계정을 만들어 두면 주소가 유지돼요.

**GitHub Pages**
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 모두 올려요.
2. Settings → Pages에서 Branch를 `main`, 폴더를 `/ (root)`로 정하고 저장해요.
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열려요.

공개 저장소여도 괜찮아요. 올라가는 것은 앱 코드와 공개용 키뿐이고, 기록은 들어 있지 않아요.

## 3. 폰에 설치

- 아이폰: Safari로 주소를 열고 공유 버튼 → **홈 화면에 추가**
- 안드로이드: Chrome으로 열고 메뉴 → **앱 설치** 또는 **홈 화면에 추가**

홈 화면에서 여는 것을 추천해요. 아이폰은 Safari 탭으로만 쓰면 한동안 안 열었을 때 기록이 지워질 수 있어요.

## 4. 연결하기

1. 한 사람이 **연결 탭 → 새로 연결 시작하기**를 눌러요. 초대 코드가 담긴 메시지가 만들어져요.
2. 그 메시지를 연인에게 보내요. 받은 사람은 **받은 코드로 연결하기**에 붙여넣어요.
3. 그다음부터는 앱을 열 때와, 열어 둔 동안 30초마다 자동으로 동기화돼요.
4. 두 사람 모두 **복구 코드 저장**을 눌러 복구 코드를 나에게 보내 두세요. 폰을 바꾸면 이 코드로 기록을 되살릴 수 있어요.

## 알아 두면 좋은 점

- **코드는 열쇠예요.** 초대 코드와 복구 코드를 가진 사람은 기록을 열 수 있어요. 연인에게만 보내고, 보낸 메시지는 지워도 괜찮아요.
- **누가 무엇을 쓰나요.** 각자 자기 기록만 쓰고, 상대 기록은 읽기만 해요. 그래서 둘이 동시에 고쳐도 서로 덮어쓰지 않아요.
- **증상 공유 끄기.** 연결 탭에서 끄면 생리 날짜만 공유돼요. 이때 서버의 내 사본에도 증상은 빠져요.
- **Supabase 무료 요금제**는 7일 동안 요청이 없으면 프로젝트가 잠시 멈춰요. 매일 쓰면 문제없고, 멈추면 대시보드에서 **Restore**를 누르면 돼요.
- **연결 끊기**를 누르면 서버에 있는 내 암호화 사본이 지워져요.
- `config.js`를 비워 두면 동기화 없이 폰에만 저장하고, 예전처럼 코드를 직접 주고받는 방식으로 동작해요.

## 파일 구성

| 파일 | 역할 |
|---|---|
| index.html | 앱 전체 |
| config.js | Supabase 주소와 공개 키 |
| schema.sql | Supabase에 만들 표와 함수 |
| sw.js | 오프라인에서도 열리게 하는 서비스 워커 |
| manifest.json, *.png | 홈 화면 앱 아이콘과 설정 |
